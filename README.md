# 📚 Student Task Manager

A clean, intuitive task management application built to help students organize assignments, track exam deadlines, and prioritize daily study goals.

![License](https://shields.io)
![Status](https://shields.io)

## ✨ Features

* **Task Management:** Create, edit, delete, and mark assignments or study tasks as completed.
* **Course & Subject Tagging:** Group tasks by specific classes, subjects, or semesters.
* **Priority & Due Dates:** Assign priority levels (High, Medium, Low) and set due dates to stay ahead of deadlines.
* **Filter & Search:** Quickly sort tasks by completion status, due date, or subject.
* **Progress Overview:** Visual summary of completed versus pending tasks.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have the following installed:
* [e.g., Node.js (v18+)]
* [e.g., npm or yarn]

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd student-task-manager
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Set up environment variables:**
   Create a `.env` file in the root directory and add your configuration:
   ```env
   PORT=3000
   DATABASE_URL=your_database_connection_string
   ```

5. **Run the application:**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your browser to view the app.
